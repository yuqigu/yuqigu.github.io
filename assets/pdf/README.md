# PDF Assets

Keep PDFs that are actively linked from the site in `assets/pdf/`.

- `YuqiGu_CV.pdf` is the current CV linked from the homepage.
- Dated CV snapshots belong in `assets/pdf/archive/cv/`.
- Publication PDFs referenced by `_bibliography/papers.bib` or `_news/*.md` should stay at the top level unless their links are updated.
